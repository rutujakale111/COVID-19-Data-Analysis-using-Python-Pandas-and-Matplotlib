# 🦠 COVID-19 Data Analysis (Maharashtra)

This project analyzes COVID-19 case data from various districts in Maharashtra using Python, Pandas, and Matplotlib. It visualizes total confirmed cases per district using bar and pie charts.

---

## 📁 Project Structure
COVID-19 Data Analysis/ ├── covid.csv # CSV file containing district-wise case data ├── cases.py # Main Python script for analysis & visualization ├── README.md # Project description └── .venv/ # (Optional) Virtual environment directory


---

## 📊 Features

- Reads and processes COVID-19 data stored in a CSV file
- Groups total confirmed cases by district
- Generates:
  - 📉 Bar chart of total confirmed cases by district
  - 🥧 Pie chart showing district-wise contribution

---

## 🛠 Requirements

Ensure Python is installed.

Install dependencies with:

```bash
pip install pandas matplotlib
````
▶️ How to Run
Place covid.csv in the project folder with the csv format.
Run the script:

```bash
python cases.py
